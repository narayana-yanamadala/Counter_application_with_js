# 🔢 Counter Application

A modern and responsive **Counter Application** built using **HTML, CSS, and JavaScript**.  
This project allows users to increase, decrease, and reset the counter value with a clean and interactive UI design.

---

## 🚀 Features

✅ Increment Counter  
✅ Decrement Counter  
✅ Reset Counter  
✅ Multiple Step Values (1, 5, 10, 100)  
✅ Keyboard Controls Support  
✅ Responsive Design  
✅ Modern UI Design  
✅ Beginner Friendly Project  

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎮 Keyboard Controls

| Key | Action |
|-----|--------|
| ↑ Arrow Key | Increase Counter |
| ↓ Arrow Key | Decrease Counter |
| Space | Increase Counter |
| Backspace | Reset Counter |
| R | Reset Counter |
